oBDSChat documentation

oBDSChat answers questions about the German oncological basic data set (oBDS). It grounds each answer in official oBDS XML schemas and the public Umsetzungsleitfaden, then shows the evidence used for the answer.

Choose your path

  • Using the application: Checkout the workflow guides.
  • Changing the application: read System architecture and the architecture decision records before using Local development.
  • Changing backend behavior: read Backend architecture and Extend the backend.
  • Changing PostgreSQL or synchronized sources: read Data storage and Change stored data, then inspect the database reference.
  • Using the REST API: open the generated REST API reference.
  • Operating a deployment: start with Runtime configuration, then use Deploy and upgrade and Operational troubleshooting.

Build these docs

From the repository root:

make docs

The static site is written to site/. Use make docs-check for the strict CI-oriented build.
